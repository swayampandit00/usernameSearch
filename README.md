# userdorking

Instant username search across 100+ platforms. Built with React Native (Expo) by swayampandit.

Type a handle. Cards stream in as available or taken.
## Run

```bash
# Install dependencies
npm install

# API + web preview
npm run dev
```

- Web UI: http://localhost:5173
- Check API: http://localhost:3001

Native:

```bash
npx expo start
```

## Stack

- React Native + Expo
- react-native-web + Vite for browser preview
- Express check API with reverse proxy at `/api`
